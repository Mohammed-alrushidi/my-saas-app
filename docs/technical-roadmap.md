## 3. Remaining Production Blockers

These must be closed (or explicitly deferred with PO sign-off) before live WhatsApp on production data:

1. **Scheduler truthful provider call (M4/R12)** — cron inserts `sent` without sending. Enabling it would create false history.
2. **Vercel Deployment Protection blocks Twilio callbacks (§7)** — no bypass for `/api/messaging/status` yet.
3. **Company suspension & subscription enforcement (A1/A2)** — suspended/deprovisioned tenants not blocked.
4. **Import transactionality & misleading `completed` (D2/D3)** — partial imports look complete.
5. **Search `.or()` injection surface (A6)** — user-controlled filter interpolated without escaping.

Non-blocking but high priority: retry path (M6), inbound STOP (M7), `CRON_SECRET` timing-safe compare (S2), idempotency gaps (M9), storage RLS (A5).
